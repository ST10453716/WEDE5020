## 1. Project Overview

Tshinakaho Haven is a proposed non-profit children's home based in Midrand, Gauteng, South Africa. The organisation aims to provide a safe, caring, supportive and family-like home for orphaned and vulnerable children.

The purpose of the Tshinakaho Haven website is to establish an online presence for the organisation and provide a central place where visitors can learn about the organisation, its mission and vision, the services it provides, the children it aims to support, and the different ways people can get involved.

The website will also provide opportunities for potential volunteers, donors, sponsors and community or business partners to enquire about supporting Tshinakaho Haven.

The website is being developed progressively throughout the project. Part 1 focuses on planning, content research, website structure and HTML development. Styling and additional functionality will be introduced during later parts of the project.

**Tagline:**  
*A place where every child feels loved, safe and at home.*

---

## 2. Website Goals and Objectives

The main goal of the website is to create a professional and informative online presence for Tshinakaho Haven.

The objectives of the website are to:

- Create awareness about Tshinakaho Haven.
- Communicate the organisation's mission, vision and core values.
- Explain the services provided by the organisation.
- Provide information about the children the organisation aims to support.
- Encourage community participation and involvement.
- Provide information about volunteering opportunities.
- Allow potential donors and sponsors to enquire about supporting the organisation.
- Encourage partnerships with businesses and community organisations.
- Provide visitors with an easy way to contact Tshinakaho Haven.
- Create a website that is simple and easy to navigate.
- Develop a strong foundation that can later be improved using CSS and JavaScript.

# 9. How to Run and Test the Website on Localhost

The Tshinakaho Haven website can be run locally using Python's built-in HTTP server.

This allows the website to be viewed and tested in a browser before it is published online.

## Requirements

Before running the website, ensure that:

- Python 3 is installed.
- The Tshinakaho Haven project has been downloaded or cloned from GitHub.
- The project has been extracted if it was downloaded as a ZIP file.
- `index.html` is located inside the main project folder.

---

## 9.1 Open the Project Folder

Open **Terminal** on macOS.

Navigate to the folder containing the project.

For example, if the project is stored in the Downloads folder:

```bash
cd ~/Downloads/Tshinakaho-Haven
```

The exact location may be different depending on where the project has been saved.

---

## 9.2 Check the Project Files

Run:

```bash
ls
```

The project should display files similar to:

```text
index.html
about.html
services.html
beneficiaries.html
enquiry.html
contact.html
images
README.md
```

If `index.html` is displayed, the correct project folder has been opened.

---

## 9.3 Start the Python Local Server

Run:

```bash
python3 -m http.server 8000
```

If the server starts correctly, Terminal should display a message similar to:

```text
Serving HTTP on 0.0.0.0 port 8000
```

Keep the Terminal window open while using the website.

---

## 9.4 Run index.html

Open a web browser such as:

- Google Chrome
- Safari
- Mozilla Firefox
- Microsoft Edge

Enter:

```text
http://localhost:8000/index.html
```

The Tshinakaho Haven Home page should open.

The following address can also be used:

```text
http://localhost:8000
```

Because the homepage is named `index.html`, the Python server will automatically load it when the root localhost address is opened.

---

## 9.5 Test the Navigation

Once the website is running, test every navigation link.

Confirm that:

- **Home** opens `index.html`.
- **About Us** opens `about.html`.
- **Services** opens `services.html`.
- **Who We Help** opens `beneficiaries.html`.
- **Enquiry / Get Involved** opens `enquiry.html`.
- **Contact Us** opens `contact.html`.

Each page should load without displaying an error.

---

## 9.6 Test the Website Content

Check that:

- All headings display correctly.
- Paragraphs display correctly.
- Lists display correctly.
- Navigation links work.
- Images display correctly.
- No content is missing.
- No broken links are displayed.

---

## 9.7 Test the Forms

Test the Enquiry and Contact forms.

Check that:

- Text fields accept information.
- Email fields accept an email address.
- The enquiry selection field works.
- Message fields accept text.
- Required fields cannot be left empty when attempting to submit the form.

**Note:** The forms currently contain basic HTML functionality only. Sending the submitted information to an email address or database will require additional functionality in a later development stage.

---

## 9.8 Test Images

Images should be stored inside the `images` folder.

For example:

```html
<img src="images/hero-diverse-children.jpg"
     alt="Diverse children learning and spending time together">
```

For this image to display, the following file must exist:

```text
images/hero-diverse-children.jpg
```

If an image does not display:

1. Check that the image exists in the `images` folder.
2. Check the image filename.
3. Check the file extension.
4. Confirm that the filename in the HTML matches the actual filename.

---

## 9.9 Cross-Browser Testing

The website should be tested using more than one web browser.

For example:

- Google Chrome
- Safari
- Mozilla Firefox
- Microsoft Edge

Navigation, content, forms and images should function correctly in each browser.

---

## 9.10 Stop the Local Server

When testing is complete, return to Terminal.

Press:

```text
Control + C
```

This will stop the Python local web server.

---
