# Tshinakaho Haven Website

## Project Overview

Tshinakaho Haven is a proposed non-profit children's home in Gauteng, South Africa. The website provides information about the organisation, the services it aims to provide, the children it supports and ways the public can get involved.

**Tagline:** A place where every child feels loved, safe and at home.

## Responsive Design

The website supports different screen sizes using CSS media queries:

- **Desktop:** Default layout
- **Tablet:** `899px` and below
- **Mobile:** `600px` and below

Layouts adjust from multiple columns to single-column layouts depending on the screen size.

## How to Run the Website Locally

To run the Tshinakaho Haven website locally:

1. Download or clone the project repository.

2. Open a terminal and navigate to the project folder.

3. Run the following command:

```bash
python3 -m http.server 8000
```

4. Open a web browser and go to:

```text
http://localhost:8000
```

5. The website will open from the Home page (`index.html`).

6. Use the navigation menu to access the other pages.

### Stop the Local Server

To stop the local server, return to the terminal and press:

```text
Ctrl + C
```
